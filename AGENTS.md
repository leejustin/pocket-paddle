This is a standalone Expo app. Its home is https://github.com/leejustin/pocket-pickle; commit and push only when the user asks. Use npm to install this standalone app's dependencies, its installed Expo CLI for local development and exports, `npm run typecheck` for targeted TypeScript validation, and `npm test` for the motion, sound, settings, and rally tests. All assets must be bundled locally. The only outside service is RevenueCat, for the Pro purchase; there is no other backend and no analytics. Never use Expo's tunnel mode or cloud builds without a new user request.
